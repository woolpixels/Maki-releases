# Maki · 巻纂

漫画装订工具。

把零散的漫画章节，或整卷文件（PDF、MOBI、AZW3、EPUB、ZIP、CBZ），自动排序、分册，一键装订成带封面与可点击目录的单行本，可输出 PDF、MOBI、EPUB 或 CBZ。

文件太大时，还可以针对 Kindle、手机、平板等设备进行阅读优化，让文件更轻、翻页和目录跳转更顺畅。

> 全程本地处理，不联网、不上传文件，也不会修改原始文件。

## 下载

前往 [**最新版 Releases**](https://github.com/woolpixels/Maki-releases/releases/latest)，在 Assets 中下载对应平台的安装包。

| 平台 | 文件 | 系统要求 |
| --- | --- | --- |
| macOS | `Maki-<版本>-arm64.dmg` | Apple Silicon Mac（M1 / M2 / M3 / M4 等），macOS 13 或更新；不支持 Intel Mac |

每个版本的发布页都附有安装包的 SHA-256 校验值，历史更新见 [CHANGELOG](CHANGELOG.md)。

## Maki 能做什么

### 整理：自动识别与排序

拖入零散章节、整卷文件或整个文件夹，Maki 会根据文件名识别章节并自动排序。支持 PDF、MOBI、AZW3、EPUB、ZIP、CBZ（图片型漫画，带 DRM 的文件无法读取），可以混合导入。ZIP / CBZ 不用手动解压：一个压缩包算一个文件，里面的图片按顺序成为它的页面；算话还是算卷，由文件名决定。

支持常见写法，例如：

- `第12话`
- `Ch.12`
- `Vol.3`
- `第1-5话`
- `卷23 第211-232话`

识别概要会提示重复、缺号和需要确认的文件。文件可以拖动排序、重命名、预览首张，也可以移除，移除后随时能恢复。

番外、特别篇、特典、附录可以从「特别收录」单独添加，自动归类、单独编号，排在正篇之后。也可以右击文件「添加至」，把内容归入正篇、番外、特典、附录等分组，或新建自己的分组；分组可以排序、折叠、改名，目录会跟着分组的顺序走。

### 分册

可以选择：

- 按每册话数或卷数自动分册
- 全部合成一册
- 用右键把某一册的首话或末话挪到相邻的册，手动调整分册；册的标题可以双击改名，右键能「合并至上一册」
- 将已经成卷的文件再合并成更少、更厚的册

特别收录可以跟随正篇，也可以合并为一册，或按类型分别成册。某一册页数明显偏少时，Maki 会建议合并。

### 校对：页面检查与阅读优化

页面分析会找出彩色、白边、纯白和异常页，可以一键灰度、自动裁、隐藏空白页，每一步修改都有操作记录，可以单独撤销和重做。

- 自动裁：按整册的共同边距裁掉多余白边，并保护扉页、章节页的设计留白
- 手动裁：按像素手动裁切，作为人工兜底
- 整册缩略图：逐页检查、对比，可对单页或批量调整

针对不同阅读设备调整输出：

- 原图模式
- 黑白 Kindle
- 彩色 Kindle
- 手机 / 平板 / 电脑
- 自定义

Maki 会显示优化前后的预计大小与压缩比例。

### 成册：封面、目录与输出

可以自动生成封面，也可以使用自己的图片。提供三种自动封面版式：

- 居中题名
- 左齐书脊
- 竖排题名

目录支持点击跳转，按番外、特典、附录分组，并可以生成章节书签，根据章节数量可使用单列到四列的版式。

输出格式可选 PDF、MOBI、EPUB 或 CBZ（CBZ 适合 Komga、Kavita 等漫画阅读器，附带章节书签与翻页方向）。单册直接生成文件，多册自动打包为 ZIP，并保存到「下载」文件夹。原始文件始终保持不变。

## 快速开始

Maki 的完整流程只有 4 步：

1. **整理**  
   拖入文件或整个文件夹，检查章节顺序、缺失、重复或识别异常。

2. **分册**  
   决定每册收录哪些章节。

3. **校对**  
   检查页面，裁切白边，并根据阅读设备调整文件大小与画质。

4. **成册**  
   选择封面样式、目录布局和输出格式，点击「开始装订」，等待生成成品。

## 安装

### macOS

1. 下载 `Maki-<版本>-arm64.dmg`
2. 双击打开 DMG
3. 将 **Maki** 拖入 **Applications**
4. 从「应用程序」中打开 Maki

Maki 已通过 Apple 开发者签名与 Apple 公证（Notarization）。

第一次打开时，如果 macOS 询问是否确定打开，选择「打开」即可。

升级新版本时，重新安装新版并选择「替换」即可。

### Windows

1. 下载 `Maki-<版本>-x64-setup.exe`
2. 双击运行安装程序
3. 按安装向导完成安装
4. 从桌面或开始菜单打开 Maki

目前 Windows 版本尚未购买代码签名证书。

如果 Windows 显示：

> Windows 已保护你的电脑

请选择：

**更多信息 → 仍要运行**

这是 Windows 对未签名且下载量较少的软件进行的 SmartScreen 提示，并不代表安装包检测到了恶意内容。

升级时直接运行新版安装包，安装到原位置即可。

### 校验安装包（可选）

在发布页复制该版本的 SHA-256，与本机计算结果比对：

```bash
# macOS
shasum -a 256 Maki-<版本>-arm64.dmg
```

```powershell
# Windows（PowerShell）
Get-FileHash .\Maki-<版本>-x64-setup.exe -Algorithm SHA256
```

## 安全与隐私

Maki 的文件处理全部在你的电脑上完成。

- 不上传文件
- 不上传漫画内容
- 不联网处理文件
- 不修改原始文件
- 不删除原始文件

校对、封面生成、目录生成与装订都在本地完成。

## 常见问题

### 顺序排错了，或者有章节没识别出来？

Maki 主要根据文件名中的数字识别章节。

可以直接修改 Maki 中用于识别的名称，例如：

`海贼王 第001话`

修改不会影响电脑里的原文件。

### Kindle 上翻页或点击目录很卡？

在「校对」中选择对应的 Kindle 输出模式。

Maki 会把页面调整到更适合设备屏幕的尺寸，通常可以明显改善翻页与目录跳转速度。

### 阅读优化会降低画质吗？

取决于选择的模式。

如果希望尽量保留细节，可以选择「原画质」。

如果选择「原图模式」，页面不会重新压缩或缩放。

### 移除文件会删除原始文件吗？

不会。

「移除」只代表不参与这一次装订，电脑里的原文件不会被删除。

### 提示这一册太大怎么办？

单个 PDF 接近约 2 GB 时，建议：

- 减少每册包含的话数或卷数
- 或在「校对」中选择更轻的输出模式降低文件体积

### 生成的文件在哪里？

默认保存在系统的「下载」文件夹。
